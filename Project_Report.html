Abstract

The "AI Invoice & Payment Reminder Bot" is a comprehensive, full-stack Software-as-a-Service (SaaS) application designed to automate the lifecycle of billing and invoicing. In traditional business environments, tracking unpaid invoices and manually sending follow-up emails is a tedious, time-consuming process prone to human error.

This project solves that problem by integrating a robust MERN stack architecture with n8n workflow automation and Google's Gemini Large Language Model (LLM).

"The system intelligently categorizes invoices as Upcoming, Due Today, or Overdue, and instructs the Gemini AI to dynamically adjust the tone of the email reminder accordingly."

2

Introduction

2.1 Problem Statement

Existing invoicing solutions are either prohibitively expensive or lack intelligent automation. Furthermore, static email templates lack the nuanced, human-like tone required to navigate the delicate nature of asking clients for money. Finally, standard SMTP email delivery from free-tier cloud platforms (like Render or AWS) is frequently blocked by firewalls to prevent spam, resulting in missed critical reminders.

2.2 Objectives

  • Develop a user-friendly React dashboard for managing clients and invoices.
  • Dynamically generate standard PDF invoices on the server side using PDFKit.
  • Leverage Google Gemini AI to draft contextual, polite, yet firm payment reminders.
  • Entirely automate the follow-up process via Node.js Cron jobs.
  • Engineer a firewall-proof email delivery system using official Gmail API integrations.

Technologies Used

Frontend (Client)

React.js, Vite, and Tailwind CSS. Hosted on the Vercel edge network for high performance.

Backend (Server)

Node.js, Express.js, MongoDB (Mongoose), and node-cron. Hosted on Render cloud infrastructure.

Automation & AI

Self-hosted n8n instance orchestrated with Docker. Google Gemini Large Language Model API.

Delivery Layer

Google Cloud Platform (GCP) Gmail API secured via OAuth 2.0 validation.

System Architecture & Data Flow

The system employs a microservices-inspired architecture. The frontend application acts as the presentation layer, entirely decoupled from the backend. The backend Node.js server handles all heavy business logic, database queries, and PDF generation. Instead of the Node.js server handling the slow and unpredictable nature of LLM generation and email dispatching, it offloads this responsibility to a dedicated n8n automation instance via Webhooks.

Backend & Cron Automation

Dynamic PDF Generation

Using the PDFKit library, the backend dynamically generates professional invoice documents on-the-fly when requested. Instead of storing physical PDF files on the server (which wastes storage and violates statelessness), the endpoint /api/invoices/:id/download streams the generated PDF directly into the response buffer.

The Intelligent Catch-Up Cron Job

A core feature of the application is the node-cron integration. A script is scheduled to run daily at 9:00 AM. It queries MongoDB for any invoices meeting strict date criteria (e.g., exactly 3 days overdue) and silently queues them for processing.

The Challenge: Free-tier cloud instances "sleep" due to inactivity. If no one visits the site at 9:00 AM, the server is asleep, and the cron job is missed entirely.

The Solution: A custom "catch-up" script was engineered to run immediately upon server boot. It checks a hidden .cron-last-run file. If the 9:00 AM schedule was missed while the server slept, the server instantly processes the queue upon waking up later in the day, guaranteeing 100% reliability.

Automation & AI Engine

6.1 Google Gemini Contextual Prompting

The Gemini LLM node is fed a highly engineered prompt that includes a dynamic reminderType variable injected by the backend (e.g., upcoming, due_today, overdue).

If the backend detects an invoice is 7 days late, it passes the overdue tag. The prompt forces Gemini to adopt a strictly professional but firm tone, demanding immediate payment. Conversely, an upcoming tag generates a warm, friendly "just checking in" message. This creates a deeply personalized experience for the end client.

6.2 Bypassing SMTP Firewalls with Gmail API

Most free-tier cloud providers (Render, AWS, DigitalOcean) block standard SMTP ports (Port 25, 465, 587) to prevent malicious actors from building spam bots. Attempting to use a standard Nodemailer setup results in connection timeouts.

To circumvent this hardware-level firewall, the project integrates directly with the Google Cloud Platform (GCP). By establishing an OAuth 2.0 consent screen and acquiring Client Credentials, n8n authenticates directly with the Gmail REST API (over Port 443). This guarantees secure, instantaneous delivery that easily bypasses all traditional SMTP firewalls.

Challenges Solved

1. Render Free Tier Memory Constraints

Problem: The n8n Docker instance repeatedly crashed with a FATAL ERROR: JavaScript heap out of memory due to Render's strict 512MB RAM limit.

Solution: Injected the NODE_OPTIONS=--max-old-space-size=400 environment variable to explicitly force the V8 engine's garbage collector to run aggressively, preventing it from exceeding the 512MB container limit.

2. Docker Container Routing Issues

Problem: n8n generated OAuth redirect URLs pointing to http://localhost:5678 because the Docker container was completely unaware of its public cloud domain.

Solution: Added the WEBHOOK_URL environment variable to explicitly define the public Render domain, overwriting internal routing and seamlessly fixing all OAuth callbacks.

3. Unverified Google OAuth Scopes

Problem: Google blocked login attempts because the application requested highly restricted scopes (Gmail API) but was not manually verified by Google security teams.

Solution: Utilized the GCP "Testing" Publishing Status and manually added the developer's email to the "Test Users" VIP list, bypassing the need for expensive security audits while maintaining functionality.

Conclusion

The AI Invoice & Payment Reminder Bot successfully demonstrates how modern web technologies (MERN) can be combined with visual automation tools (n8n) and Artificial Intelligence (Gemini) to solve real-world business problems.
